# SegmentScraper v1.12.7 — Available episodes and timestamp review

This release follows the v1.12.6 userscript on `main`. It includes the timestamp-review work and the provider catalogue fixes in this branch. Desktop remains **Alpha 0.1**.

## Features

- Add manual Intro/Recap/Outro marking from the player, with explicit title/episode confirmation, start/end marks and short boundary previews. The panel starts collapsed on every provider.
- Filter timestamp comparison, JSON export and upload approval by segment type, including desktop comparison. Changing the filter clears approvals.
- Collect Prime season episode lists and the complete Videoland programme catalogue without requiring playback of every episode just to count them. Videoland follows section and episode pagination, batches up to eight episode pages and falls back to individual pages when batching is unsupported.

## Bug fixes

- When episode totals differ, allow TVDB episodes dated in the future and undated placeholders absent from matching provider numbering to be excluded. Episodes already available from the provider still count even if TVDB has a later or unknown date. Malformed dates and conflicting metadata do not excuse a mismatch.
- Verify missing dates against individual TVDB episode records where possible, refresh failed mappings on retry, and show the actual mismatch and extra episode numbers in timestamp review.
- Wait for the Videoland catalogue before validating export/upload. Detect repeated pagination contents, stop failed/partial catalogue checks and identify the affected programme, season and cursor in errors.
- Retry TV titles ending in “De Serie” or “The Series” without that suffix only when the original search finds no result of the requested media type. Require an exact shortened title and, for automatic lookup, the supplied year. This resolves Videoland's “Gooische Vrouwen De Serie” to the TV series rather than the films.
- Preserve revised timestamp observations while deduplicating exact repeats. Competing ranges require a reviewed selection, and changed captures invalidate stale approvals.
- Preserve valid zero-second starts; reject missing, invalid, reversed and out-of-duration boundaries. Pause manual marking at the actual player clock and handle interrupted previews safely.

## Maintenance and scope

- Keep TVDB/IntroDB/TMDB credentials together in collapsible settings and show the running userscript version.
- Remove unused helpers and the experimental Prime season timestamp replay/diagnostic code. Prime timestamps still require opening each episode; episode counting is separate from timestamp capture.
- Share applicable lookup, mapping and validation rules between the userscript and desktop, with regenerated client bundles and parity tests.
- Keep existing movie policies: online movie capture is enabled only for Netflix and excludes outros when an extra scene is known. Desktop retains its reviewed scene-safe outro/scene workflow. Uploads always require manual review and approval.

## Validation

- 290 automated tests passed, covering both clients, generated userscript consistency, released/undated/early provider episodes, pagination, IMDb fallback and upload review.
- Desktop generated-core parity and whitespace checks passed.
- Live IMDb requests verified the full provider title returns no results and the shortened query returns series `tt0477217`.
- Automated and simulated-player tests do not establish universal live provider compatibility. The latest Videoland pagination changes still need confirmation in a signed-in live session.

## Update

The userscript keeps its existing name, namespace and update URLs. Install the attached `SegmentScraper.user.js` or update from `main` after this release is merged. Reload provider tabs after installation.

If you installed a local test build numbered 1.12.8–1.12.14, replace it with v1.12.7 manually once: an update manager will not automatically downgrade that higher local test version. Clear any incorrect Prime timestamp candidates collected by the earlier experimental season-fetch builds before review/upload.

Windows Setup and Portable executables are built by the release workflow. Their filename version is 1.12.7; the desktop product remains Alpha 0.1.
