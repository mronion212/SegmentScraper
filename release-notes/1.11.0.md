## Desktop

- English review and IntroDB upload workflow with IMDb lookup, shared TVDB/TMDB checks, duplicate filtering, visible progress, and an audited admin override.
- Required update dialog when a newer stable Windows release is available.
- Automatic FFmpeg ending analysis proposes credits and mid-/post-credits boundaries, with a 12x overview and short boundary clips for manual review.
- The user must verify all output and explicitly upload. Visual detection is heuristic; black transitions alone do not prove scene boundaries.
- Multiple real extra scenes remain in the local report and block upload because IntroDB currently models one scene range.

## Userscript and maintenance

- The online userscript continues excluding movie outros when an extra scene is known.
- Applicable rules are shared between clients; CI checks generated code and regression tests.

## Validation and limitations

- 167 local tests passed, including real FFmpeg scans of synthetic video and preview decoding.
- In-app playback is not yet confirmed: the Codex test browser crashed on Play, although generated previews decode correctly and HTTP range requests pass.
- Windows builds are unsigned. No live IntroDB submissions were made during testing.
- Older versions without the update checker require a one-time manual installation.
