# SegmentScraper 1.12.1

- Reduce analysis frames before scaling; sample the 12x overview before speeding it up instead of processing every 4K frame.
- Prepare short original-speed boundary clips when opened, avoiding automatic repeated provider seeks. Detected boundaries remain one click away.
- Add an optional last-15-minute scan, explicit coverage warnings, scan speed and approximate time remaining. The last-quarter default is unchanged.
- Black transitions now use the same 0.5-second sampling interval as visual detection. Final boundary review remains required; shorter coverage cannot establish absence of earlier scenes.

Validation: full userscript/desktop regression suite, real FFmpeg scene fixtures and overview timing. A local synthetic 20-second 4K/24fps H.264 benchmark took 2.71-2.75 seconds before and 1.36-1.40 seconds after (two runs each). This measures local processing, not provider throughput or 4K HEVC decoding; network and source decoding can still dominate.

These changes affect desktop analysis only. IntroDB payloads, online movie exclusion rules and explicit upload checks are unchanged.
