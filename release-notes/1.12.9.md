# SegmentScraper v1.12.9 — Choose the correct title version

This update builds on v1.12.7 with improved title identification in the userscript and shared TVDB validation in Desktop Alpha 0.1.

- In the userscript, show IMDb titles, start years and IDs when multiple versions could match, such as Bestemming X and Bestemming X Nederland. An exact title alone no longer silently selects a regional version; a unique matching start year can still resolve the title automatically.

- In the userscript, retain automatic IMDb search choices until the panel is opened. Ambiguous titles now show their available versions immediately, without requiring another click on Search. Recreated panels retain the choices too.
- Present multiple IMDb matches as a request to choose the version being watched, instead of reporting a lookup failure.
- Apply manual IMDb corrections to already captured segments belonging to that series, so subsequent TVDB checks use the corrected identity.
- In both clients, block TVDB mapping when the IMDb ID is missing or segments contain different IMDb IDs. Desktop keeps its explicit IMDb result selection.
