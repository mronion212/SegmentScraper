# SegmentScraper v1.12.8 — Confirm the correct title version

- In the userscript, show a choice of IMDb titles, years and IDs when a title could refer to multiple versions, such as Bestemming X and Bestemming X Nederland. An exact title alone no longer silently selects a regional version; a unique matching start year can still resolve the title automatically.
- Apply manual IMDb corrections to already captured segments belonging to that series, so subsequent TVDB checks use the corrected identity.
- In both clients, block TVDB mapping when the IMDb ID is missing or segments contain different IMDb IDs. Desktop keeps its explicit IMDb result selection.
