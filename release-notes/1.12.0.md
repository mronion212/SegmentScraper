## Resume your work and review boundaries in one workspace

- Save inspection tasks, review drafts, analyses, preview clips and upload history locally. Interrupted tasks can be restarted after reopening the app.
- Require fresh upload checks and manual confirmation after restart. Detect changed local videos before reusing their analysis or uploading timestamps.
- Add a review file list, status filters, a single video player, a segment timeline, source timecodes, 0.1-second stepping, boundary editing and Undo.
- Create short clips on demand at other source positions, and save clips for an external player.
- Generate analysis and the accelerated overview in one FFmpeg decode pass. Reuse unchanged local analyses and keep unchanged queue rows mounted.
- Use WebM previews with explicit playback controls. Reject invalid IntroDB timestamps instead of silently treating them as duplicates.

Validation: 173 automated tests, including real FFmpeg video processing, restart/cache/source-change scenarios, saved upload receipts and HTTP range seeking. Browser UI verified playback, boundary editing, saved-draft recovery and on-demand clips. No live IntroDB uploads were made.

Detection remains heuristic and requires manual review. Multiple real extra scenes remain local under the current IntroDB model. Provider tasks require reconnection/reinspection after restart. Interrupted downloads restart from the beginning. Hardware acceleration, automatic installer downloading and a trained scene detector are not part of this release.
